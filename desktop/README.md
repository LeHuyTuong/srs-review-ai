A new Flutter project.

## Chạy web

Port web đã cố định ở `web_dev_config.yaml` (`http://localhost:54613`) nên origin
không đổi mỗi lần chạy. Muốn Chrome dùng profile cố định (không phải đăng nhập
lại mỗi lần), chạy:

```sh
powershell -ExecutionPolicy Bypass -File tool\dev_web.ps1
```

Xem [cấu hình local](../docs/local-environment.md).
