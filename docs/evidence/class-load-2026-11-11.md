# Tải review SRS của một lớp — số thực tế

Nguồn: Tường cung cấp ngày 11/11/2026 (số của một lớp thực tế, không phải giả định).

| Thông số | Giá trị |
|---|---|
| Sinh viên / lớp | 30 |
| Nhóm / lớp | 6–7 |
| Lần nộp report / nhóm | 3–4 |
| Phiên bản / report | 2–3 |
| Thời gian review 1 tài liệu | 15 phút |

Tính:
- Tài liệu / lớp = 6×3×2 = **36** đến 7×4×3 = **84**
- Thời gian / lớp = 36×15 = 540′ = **9 giờ** đến 84×15 = 1260′ = **21 giờ**
